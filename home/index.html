How it works

Addresses

  • acme.localhost:4100 opens an app's default version.
  • dev.acme.localhost:4100 opens one version of it.
  • acme.localhost:4100/dev/… sends you to that version.
  • Each address is its own origin, so apps never share cookies, storage or service workers.

Adding an app

  • In the launcher: a name, and a port such as 5173 or a URL.
  • When starting galileo: npm start -- --target web=5173.
  • From a program: POST /__xo/api/targets with { "name", "upstream" }.
  • galileo keeps the list in data/targets.json, so apps stay across restarts.

Ports

  • galileo starts nothing. It routes to whatever answers on the app's port.
  • An app that isn't answering yet gets a page that waits and retries every 2 seconds.
  • WebSockets go straight through, so hot reload keeps working.
  • galileo itself listens on 127.0.0.1:4100 only.

telescope

  • Every HTML page gets telescope: switch app, version or page, inspect, comment, capture, record, ask the agent.
  • Comments, captures and designs stay in galileo's data/ folder.
  • Each app's telescope design is set in the launcher.

For programs

  • GET /__xo/health: the app names, cheap enough to poll.
  • GET /__xo/api/targets: every app in detail, for pages on this origin.
  • Mounted in another server, as xo-client does, galileo answers only *.localhost and /__xo/*.
